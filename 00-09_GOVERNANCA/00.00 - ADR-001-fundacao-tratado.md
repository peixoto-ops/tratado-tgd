# ADR-001 — Fundação do Tratado de Teoria Geral do Direito

**Data:** 2026-06-26
**Status:** APROVADO
**Autores:** HERMES (Aspire) → Apollo (Inspirion)

## Contexto
O ecossistema LKE 5.0 atingiu maturidade para produção autônoma de obra doutrinária.
O Apollo tem capacidade ociosa e perfis de subagentes adequados para execução contínua.

## Decisão

### Arquitetura
1. **Repositório** `tratado-tgd` no Apollo, estrutura Johnny.Decimal
2. **Orquestração** por 8 cronjobs Hermes no Aspire, com SSH para execução no Apollo
3. **Pipelines** em 6 fases (0-5) com gates de integridade 2.5 e 4.5
4. **Modelos**: DeepSeek-V3 (redação), Qwen 7B (juízo/reflexão), Llama 3.1 (extração)

### Autonomia
1. NENHUM gate humano obrigatório — o sistema executa autonomamente
2. Humano é REVISOR — pode ou não intervir (padrão YOLO mode, ADR-029)
3. Resultados notificados via Telegram para leitura passiva
4. PATCH/MINOR autônomos. MAJOR notifica mas não bloqueia

### Conteúdo
1. 20 capítulos em 5 Partes
2. Cada capítulo: teoria + jurisprudência + prática + roteiro de atualização
3. Fontes: MCP local (acervo SQLite, Zotero) > repositórios acadêmicos > fallback web
4. Ontologia obrigatória via CDDir (340-349)

## Consequências
- Positivas: Obra autoproduzida, atualizada continuamente, integrada ao dia a dia
- Negativas: Risco de alucinação (mitigado por gates), dependência de APIs (mitigado por MCP local)
- Neutras: Primeira versão em 6 meses
