# ADR-002: Estrutura das Partes do Tratado

**Status:** Aceito
**Data:** 30/jun/2026
**Decisão:** A faixa 30-39 é Epistemologia (não Dogmática)

## Contexto
O Johnny.Decimal original previa 30-39 como Dogmática (ramos do Direito).
O Cap.3 (Epistemologia dos Sistemas Agênticos) foi escrito e está na faixa 30-39.
Havia dois diretórios concorrentes (30-39_DOGMATICA vazio, 30-39_EPISTEMOLOGIA com conteúdo).

## Decisão
1. 30-39_EPISTEMOLOGIA: Epistemologia dos Sistemas Agênticos de IA Jurídica (Cap.3)
2. 40-49_APLICACAO_DOGMATICA: Dogmática aplicada + casos do escritório
3. 00-09_GOVERNANCA/02.00: Mapa de Cobertura CDDir como artefato obrigatório

## Justificativa
A progressão Ontologia (Cap.1) → Metodologia (Cap.2) → Epistemologia (Cap.3) →
Dogmática Aplicada (Cap.4+) é mais coerente e correspondente à sequência lógica
da obra: do ser para o como, para o que sabemos, para o que há, para o que fazer.

## Consequências
- Positivas: Progressão lógica limpa, Cap.3 já existe e não precisa ser movido
- Negativas: Dogmática empurrada para 40-49, exigindo rearranjo numérico
- Risco: Nenhum — o Cap.3 já está escrito e maduro
