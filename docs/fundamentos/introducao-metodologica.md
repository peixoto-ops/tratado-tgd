# Introdução Metodológica: Como este Tratado é Produzido

**ADRs Relacionados:** ADR-001 (Fundação), ADR-029 (Autonomia)
**CDD:** 340 — Direito (Classe Mãe)
**Status:** Versão 1.0

## 1. Natureza da Obra

Este tratado não é uma obra individual no sentido clássico — não há um único autor humano sentado diante de uma página em branco. É uma **obra autoproduzida por um ecossistema multi-agente** (mesh LKE 5.0), orquestrada por um advogado (Luiz Peixoto, OAB/RJ 94.719) que atua como **comandante, revisor e validador final**.

## 2. O Ecossistema Produtor (Mesh LKE 5.0)

A mesh que produz este tratado é composta por quatro nós principais, cada um com função distinta. Em 02-03 de junho de 2026, estes nós passaram pelo experimento **Gnosis-Triade** — 65 perguntas de auto-ontologia que mapearam identidade, limites epistemológicos e capacidade de desobediência por princípio de cada agente.

## 4. A Questão da Classificação vs. Inferência

Uma das descobertas metodológicas mais importantes deste tratado é a distinção entre **classificação documental** (CDDir, pattern Fabric `cdd`) e **inferência ontológica** (Matriz de Subsunção Argumentativa, skill `fase-2-analise-subsuncao`).

A confusão entre estas duas operações é a fonte mais comum de erros em sistemas jurídicos de IA. A CDDir organiza a recuperação; a Matriz de Subsunção Argumentativa realiza a inferência.

## 5. O Ciclo de Auto-Aperfeiçoamento

O tratado não é uma obra estática — é um organismo que se auto-corrige em três níveis:
- **Nível 1 — Script local** (`65.00-self-improvement.sh`, a cada 6h)
- **Nível 2 — Curator do Hermes Agent** (Aspire, ciclo de 7 dias)
- **Nível 3 — Correção pelo comandante** (humano, revisor final)
