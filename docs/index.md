## Princípio Metodológico Fundamental

**CDD é para indexar, não para inferir.** A Classificação Decimal do Direito organiza a recuperação de precedentes por assunto macro. A subsunção (aplicação do precedente ao caso concreto) é feita pela Matriz de Subsunção Argumentativa (skill `fase-2-analise-subsuncao`). Esta distinção é a base epistemológica de todo o tratado.
